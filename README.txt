OP Menu (Fabric, Minecraft 1.21.11, client-side)

BUILD
  1. Install JDK 21 and Gradle 9.4.1  (Loom 1.14 needs Gradle 9.2 or newer, so NOT Gradle 8.x).
  2. In this folder run:   gradle build
  3. Your mod is build/libs/opgui-1.1.0+1.21.11.jar  (NOT the -sources jar).

INSTALL
  Put the jar and Fabric API (for 1.21.11) in your .minecraft/mods folder (Fabric Loader 0.18+).
  Nothing is needed on the server. You just have to be OP there (or have cheats on in singleplayer).

USE
  Press G (rebindable under Controls > OP Menu).
  Look at a player first and they're pre-selected as the target.
